AnswerBot-Screen v2.1 使用说明（工作电脑快速上手）
================================================

一、运行
  1. 解压本包到任意目录（如 D:\AnswerBot）
  2. 双击 AnswerBot.exe（建议：右键 → 以管理员身份运行）

二、v2.1 主要变化（对比旧版）
  - 全屏抓取：不再认窗口标题，VMware / 天翼云电脑 / 网页考试都行
  - 自动定位题目区域：悬浮窗、倒计时等不干扰识别
  - 30 秒兜底识别：换题漏判也会自动补识别（同题不重复显示）
  - 右下角托盘图标：隐藏后点托盘一键找回；托盘可退出程序
  - 悬浮窗置顶强化：显示答案时始终在最前

三、首次配置（重要）
  config.json 在 exe 同目录（已带好千问 API Key，一般不用改）：
  - ai_provider: "qwen"（主识别）
  - capture_monitor: 0 = 全部显示器合并（默认）；题目总在某一屏可改 1/2
  - fallback_interval_ms: 30000（兜底间隔；考试长可调大省钱）

四、使用流程
  1. 打开考试系统（窗口模式即可；独占全屏模式抓不到，见排障）
  2. 启动 AnswerBot.exe → 悬浮窗显示「就绪：监听中」，右下角出托盘图标
  3. 开始答题：换题后自动识别，答案显示在屏幕 1 右上角悬浮窗
  4. 悬浮窗可拖拽；右键悬浮窗 或 托盘图标 → 隐藏/暂停/退出
  5. 全局热键 Ctrl+Alt+H：隐藏/显示悬浮窗

五、手动触发（可选辅助）
  点悬浮窗「绑定按键」→ 按想用的键（推荐键盘组合键）→ 完成。
  注意：虚拟机/云电脑内鼠标侧键可能被客户机截获不生效，以 30 秒兜底为准。

六、排障
  - 一直「识别失败」→ 检查 Key/网络；日志见 logs\answerbot.log
  - 全屏抓取黑屏 → 考试客户端是「独占全屏」模式，改为「窗口/无边框全屏」
  - 换题后不出答案 → 等 30 秒兜底必出；仍不出看日志
  - 识别慢 → config.json 调小 detect_interval_ms（如 500）、n_stable（如 4）

七、注意
  - config.json 含 API Key，请勿外传
  - 考试时如遇监控，Ctrl+Alt+H 快速隐藏，托盘一键恢复
