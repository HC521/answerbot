AnswerBot-Screen v2.6 使用说明（工作电脑 / 同事快速上手）
=========================================================

一、运行
  1. 解压本包到任意目录（如 D:\AnswerBot）
  2. 双击 AnswerBot.exe（建议：右键 → 以管理员身份运行）

二、第一次启动：粘贴 API Key（不用改任何文件）
  首次运行会弹出「AnswerBot 首次配置」窗口，里面是三个标签页：
  1. 选标签页：DeepSeek（推荐）/ 千问 / 豆包
  2. 把 API Key 粘贴进输入框（可勾「显示」核对）
  3. 点「测试连接」看到 ✅ 再继续（可选，但建议试一次）
  4. 点「保存并启动 ▶」→ 程序开始监听
  说明：Key 只保存在本机 config.json，不会上传；同事各自填自己的 Key。

三、之后随时更换 / 新增 Key（v2.6 新增）
  不用重启、不用改文件：
  - 点悬浮窗右上角【⚙】按钮
  - 或者：悬浮窗右键 → 「⚙ 设置 API Key…」
  - 或者：右下角托盘图标 → 「⚙ 设置 API Key…」
  在弹出的窗口里选标签页粘贴新 Key → 点「保存」立即生效，模型菜单同步刷新。

四、切换模型（DeepSeek / 千问 / 豆包）
  三个入口，效果一样（立即生效并记住）：
  - 悬浮窗左上角「DeepSeek ▾」→ 点一下下拉选择
  - 悬浮窗右键 → 模型
  - 右下角托盘图标 → 模型切换
  状态行会显示本题实际用的模型和耗时，例如：
    识别完成（第 3 题）· DeepSeek · 1.4s 把握度 98%

五、使用流程
  1. 打开考试系统，建议窗口最大化 / 无边框全屏（独占全屏抓不到，见排障）
  2. 启动 AnswerBot → 悬浮窗显示「就绪：监听中（全屏）· DeepSeek」，右下角托盘图标
  3. 换题自动识别；漏了等 30 秒兜底，或点悬浮窗「保底」立即识别
  4. 悬浮窗可拖拽；右键悬浮窗 / 托盘 → 隐藏/暂停/退出；Ctrl+Alt+H 快速隐藏/恢复

六、手动触发（可选）
  点「绑定按键」→ 按想用的键（鼠标侧键或键盘组合）。虚拟机/云电脑内鼠标侧键可能不生效，
  以 30 秒兜底和「保底」按钮为准。

七、排障
  - 只有托盘图标、看不到小窗 → 点托盘「窗口移回主屏」（v2.5 起也会自动召回）
  - 换题不识别 → 确认考试窗口是「窗口/无边框全屏」而非独占全屏；可把 config.json 的
    t_change_block 调低（如 4）
  - 频繁误识别（桌面有动画/视频） → t_change_block 调高（如 7）
  - 独占全屏抓不到（画面全黑） → 考试客户端改窗口模式
  - 识别失败 → 看状态行原因；详细日志在同目录 logs\answerbot.log

八、注意
  - config.json 含 API Key，勿外传、勿提交到代码库
  - 考试时 Ctrl+Alt+H 快速隐藏悬浮窗，托盘一键恢复
